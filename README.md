# Documentación del Proyecto - Sistema de Catálogo y Turnos

Rivadeneira Marina

Este repositorio centraliza toda la documentación técnica, arquitectónica y de diseño del sistema. Su propósito es consolidar las decisiones de ingeniería, diagramas de arquitectura, modelos de datos y la bitácora de evolución del proyecto.

## Estructura del Repositorio:

- **/adr:** Registros de Decisiones de Arquitectura (Architecture Decision Records). Contiene las justificaciones tecnicas, alternativas descartadas y consecuencias de las decisiones tomadas.
- **/diagrams:** Diagramas de arquitectura, componentes, secuencia y flujos del sistema.
- **/data-model:** Definicion de entidades, esquemas de bases de datos relacionales y estrategias de sincronizacion.
- **/specs:** Requerimientos funcionales, no funcionales y contratos de API.
